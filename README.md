# Metric_maximisation

## Run inference

The main.py aims at computing the binarisation step from MaxExp and from the others reference methods studied in the paper.
To do so, config.ini is used to input all implemented necessary parameters for the run.

## Figs and tests 
In order to reproduce figures linked to models and score maximiation displayed in the paper, and to run the permutation test leading to the p-value of the score difference, please referred to the tests_and_figs.py script. The lasts sections of the latter concerned use examples, and running the script as it is will plots Figure 2 and calibration curves of the differents models and subsets.
